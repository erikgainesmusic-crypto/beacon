# Erik Gaines

A first website, shipped through GitHub and Cloudflare Pages.

This repo is a single static file. No framework, no build.

## Cloudflare Pages settings

| Field | Value |
| --- | --- |
| Production branch | `main` |
| Build command | `exit 0` |
| Build output directory | `/` |

After the first deploy, the site lives at `https://<project-name>.pages.dev`.

Push to `main` and Cloudflare rebuilds it.
